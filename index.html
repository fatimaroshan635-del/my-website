Writing DIGITAL PAKISTAN — FULL MASTER BUILD PROMPT 1. PROJECT OVERVIEW Build a complete, professional, mobile-first Pakistani digital services platform named Digital Pakistan. The website must provide useful, trustworthy, easy-to-access information and tools for people across Pakistan, including Punjab, Sindh, Khyber Pakhtunkhwa, Balochistan, Islamabad, Gilgit-Baltistan and Azad Jammu & Kashmir. The interface must support both Urdu and English, including Urdu right-to-left layout and English left-to-right layout. This must be a real, usable website—not merely a visual demo or a collection of non-working buttons. 2. IMPORTANT PRESERVATION RULES If an existing website or codebase is provided, inspect it before making changes. Create a backup or restore point before modifying existing files. Preserve all existing working features, content, branding and routes unless explicitly instructed otherwise. Do not delete or replace existing project files without a clear reason. If the project is a single-file GitHub Pages website, provide a complete, self-contained index.html that includes its required HTML, CSS and JavaScript. If the project uses a backend or database, retain its architecture and integrate with it properly. Never claim that a feature works unless it has been implemented and tested. Before delivery, test navigation, search, forms, language switching and mobile responsiveness. 3. BRANDING AND DESIGN Brand name: Digital Pakistan Tagline: Pakistan Ki Digital Duniya | Pakistan's Digital World Design a premium, modern, trustworthy Pakistani platform. Attractive header with logo and language selector. Search bar prominently displayed on the homepage. Fixed or accessible bottom navigation on mobile where appropriate. Readable Urdu typography and proper RTL support. Accessible buttons, focus states and sufficient contrast. Fast loading and minimal unnecessary animations. Avoid overcrowding and excessive scrolling. 4. HOMEPAGE Create a complete homepage containing: Brand header and navigation. Urdu/English language switcher. Global search with relevant results. Featured government services. Popular categories. Latest verified announcements and schemes. Province selector. Useful shortcuts and official contact links. AI and creator tools. Developer portfolio section. Footer with Privacy Policy, Terms, Disclaimer and Contact pages. Every visible navigation item and button must have a defined action. Remove placeholder buttons or clearly label unavailable integrations. 5. VEHICLE SERVICES Create a dedicated vehicle-services section for cars and motorcycles. Benefits and application process. Official source URL. Last verified date. Publication status: Draft, Published or Archived. Manage categories and announcements. Validate required fields. Log important administrative actions. Confirm destructive actions before deleting records. Security requirements: Use a real authentication provider and backend authorization. Store records in a proper database with access-control rules. Only authorized administrators may create or publish public records. Keep API secrets and privileged credentials on the server, never in public HTML or JavaScript. Apply input validation, output escaping, rate limiting and appropriate protection against unauthorized requests. Never implement a fake password screen that provides no real security. For a static GitHub Pages version, provide only a clearly labelled local draft manager until a secure backend is configured. Local browser storage is not a shared database and is not secure administrator authentication. 9. JOBS AND CAREER SERVICES Create sections for: Government jobs. Private-sector jobs.
